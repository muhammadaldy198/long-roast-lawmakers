One satirical sentence, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF: a Node program writes exactly one sentence to `entry.txt` — Congress will regulate your algorithm, your wallet, and your feed, but it cannot regulate a Word document into a PDF, so the law arrives as a screenshot.

## Run it

```sh
node main.ts
```
